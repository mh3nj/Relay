# Support

For bugs and reproducible problems, use [GitHub Issues](https://github.com/mh3nj/Relay/issues) once issue reporting is enabled for the repository.

Before opening a report:

- Check whether the problem is already reported.
- Include the browser and operating system, steps to reproduce, expected behavior, and actual behavior.
- Mention whether the issue occurs online, offline, or in an installed PWA window.
- Remove API keys, private backups, personal data, and sensitive logs.

Use the private reporting route in `SECURITY.md` for security concerns. General issues are not a private channel.

Relay is maintained by an individual. There is no promised response time, support SLA, or guarantee that every report will be resolved.
